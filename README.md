# Ankit Dental Studio

A modern, gentle-dentistry clinic landing page. Single-file static site — no build step, no framework.

## Stack
Plain HTML/CSS/JS, Google Fonts (Plus Jakarta Sans + Fraunces). Scroll reveal via `IntersectionObserver`.

## Run locally
```bash
python3 -m http.server 8080
# open http://localhost:8080
```

## Notes
- The appointment form is a front-end-only demo — submissions are not sent anywhere.
- All contact details (address, phone, email) are placeholders.
